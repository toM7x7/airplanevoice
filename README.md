## 起動

Node.js 22.12以降を使用します。

```sh
npm ci
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。初回の「飛ばす」または音ボタンで音声を有効にします。ヘッドホンを推奨します。

```sh
npm test            # コアの自動テスト
npm run check      # TypeScript
npm run build      # dist/ に静的Webアプリを出力
npm run preview    # ビルドのローカル確認
```

共有版はビルド後に`npm run dev:shared`で起動し、`http://127.0.0.1:8787/?shared=1`を開きます。`npm run check:worker`でWorkerの型を生成・確認、`npm run test:shared`で2ブラウザとVR模擬を接続して検証します。[配置と実機チェック](docs/deployment.md)。

ブラウザ操作の再検証は、開発サーバーを起動してから実行します。

```sh
npx playwright install chromium
npm run test:browser
npm run test:airspace
npm run test:workshop
npm run test:quality   # Vite上で同一飛行・モデル寸法の比較画像と状態を保存
npm run test:observation
npm run test:evolution
npm run test:vr
npm run test:audio
npm run test:trail
npm run test:transfer
# 配布版のpreviewを起動した状態で:
npm run test:offline
```

## 遊び方

1. 「大きな旋回」「八の字」「ゆるい起伏」を選ぶか、「一筆で描く」で航路を描きます。
2. 点をドラッグし、高さを調整します。機体が飛べるよう、線は滑らかに整えられます。
3. 「この航路で飛ばす」を押すと設計線が消えます。ドラッグで空を見回し、目のボタンで拡大できます。
4. 各地点で発した音が、距離に応じて遅れて届きます。その発音位置に薄い線と輪が現れます。
5. 一周後は「もう一周、眺める」。次周は低い音の層だけが少し変わります。眺める場所を変えると、同じ飛行でも音の到来が変わります。

Enterで開始、Spaceで一時停止、Escで機体情報を閉じる（情報が閉じていれば編集へ）、Fで全画面表示。入力欄・ボタンにフォーカスがある間は、通常のキーボード操作を優先します。

航路と機体は同じブラウザのlocalStorageに保存します。音・表示の設定から音量、遅延倍率、控えめな表示を選び、体験ログをJSONでダウンロードできます。タブを離れたときは一時停止します。

### つくる実験室

1. 「つくる実験室 →」を開き、胴体・翼・エンジン数を調整。「機体を近くで見る」で形を見ます。
2. 「2 航路」で地図にA/Bを置き、「この2点で航路を作る」。幅・高度・速度・ゆらぎを変えます。
3. シードを変えると別のゆらぎ。同じシードへ戻すと同じ航路を再現します。傾きの追従時間で、曲がり始めの印象を比べられます。
4. 「レシピ」でJSONを編集・適用し、気に入った設定を書き出します。成立しない値や航路は、理由を表示して直前の有効な状態を保ちます。
5. 飛ばして観察し、また編集へ戻ります。

A/Bは空中の通過点です。2地点を通るのはST-01で、追加機は比較用に位置をずらします。離発着や地上走行は今後の段階です。

### 周回ごとに、少し違う空へ

「周回ごとに変化して飛び続ける」をONにして飛ばします。初周は設定した航路、次からは旋回の幅と起伏が少しずつ変わります。「変化の幅」で変わり方を調整できます。全機の音が届いた後に6秒休み、次の航路で飛行を始めます。

OFFにすると現在の飛行で自動継続を終了。「ひと休み」は周回間にも使えます。「この航路を残して編集」で気に入った周回を端末に保存し、「航路を描き直す」では最初の航路へ戻れます。v0.6.0から周回設定も保存します。再読み込み後は編集画面から始まり、自動で発進しません。

最初の航路を基準にするため、変化が無制限に累積することはありません。生成条件と天候・他機などの発展先は[条件から変わり続ける飛行](docs/procedural-flight.md)に整理しています。現在の変化は航路の生成規則によるもので、AI・気象・機体間の相互作用は未接続です。

### 機体の情報を見る

空の機体をクリック／タップするか、右上の「機体情報」を押します。速度（km/h・m/s）、進行方向（北0°）、高さ、現在地からの距離を表示します。複数機ではST-01〜03から切り替えられます。

「この機体の方を向く」で、その瞬間の機体へ視線を向けられます。見る位置は地上のままです。情報を見る機体と、音を注目して聴く機体は別々に選べます。スマホ幅では情報が空の下に並びます。

選択を外すには機体情報の解除ボタン、または何もない空をクリック／タップ。VRでは何もない空へトリガーを押します。音も「空全体を聴く」へ戻ります。v0.6.0では古い線・波紋の透明度を下げ、視界で機体と重なる箇所の余白も広げました。

### 空のにぎわいを変える

「空のにぎわい」で1〜3機を選びます。追加機は描いた航路を別の位置で飛び、尾翼の色で見分けられます。開始間隔は同時・8秒・16秒。「注目機を聴く」と「空全体を聴く」は飛行中にも切り替えられます。ST-01〜03を押すと、その機体に注目し、ほかの音を控えめにします。カメラは自分で向けます。

「管制案内を表示する」をONにすると、予定や飛行開始を字幕で案内します。現時点では定型案内で、AI・音声読み上げは未接続です。機体が近くを通る間は、字幕表示を控えます。v0.6.0から機数・開始間隔も保存し、保存設定の再読込・取り込み後は空全体を聴く状態になります。

## この版の範囲

| 実装済み                                     | 状態                                                 |
| -------------------------------------------- | ---------------------------------------------------- |
| 航路プリセット・描線・制御点編集・高さ・Undo | PCのポインター操作、狭い画面に対応                   |
| 機体の寸法・配置、2地点航路、シード、JSON | 画面とレシピの共通検証、書き出し、保存復元 |
| 傾きの追従、描画の軽量化 | 時刻から求めるバンクの平滑化、窓の一括描画、遠距離の細部省略 |
| オフライン再開 | 配布版を初回保存したブラウザで単体体験を再開 |
| 閉曲線のコンパイル                           | 平滑化、旋回拡大、高度勾配制限、等距離サンプル       |
| 1〜3機の飛行と開始間隔                        | 機体ごとに位置・向き・バンク、発音・音到来を管理       |
| 機体を選んで観察 | 速度・進行方向・高さ・距離。待機・終了時は数値を表示しない |
| 周回ごとの変化・自動継続 | 音到来後に次の航路生成、待機・停止・気に入った周回の保存 |
| 機体別の音量配分                             | 注目／全体、滑らかな切り替え、機体ごとの発音枠       |
| 管制字幕                                     | 任意表示、飛行イベントからの定型案内、間隔・寿命あり |
| 音の到来                                     | 発音位置と観測者の距離、遅延倍率、Doppler近似        |
| 音航跡                                       | 到来済みの発音位置に線・輪を表示、寿命・数の上限あり |
| 周回・ルール演出                             | 次周の低音層を変更、AIサービス不要                   |
| 保存・ログ・初期化                           | 端末内保存、JSON出力、Reset                          |

機体は寸法を変えられる検証用メッシュ、音は共通の合成音です。初期速度58 m/s、傾きの追従は観察体験の表現モデルです。形状から揚力・音色を推定する処理や、追加機の衝突回避はありません。共有試作は単機・2端末から検証します。実機の飛行性能、録音素材の音色、MR、LLM連携は未実装です。
