# 音航跡 / SOUND TRAIL

空にひとつの航路を描き、四発機を眺め、あとから届く音を待つ。

**独立したWebアプリの単体検証版（v0.2）です。** React Three Fiber、TypeScript、Web Audioで動きます。最大3機の響きを聴き比べ、飛行イベントに応じた管制字幕を試せます。複数Questで同じ空を共有する到達目標に向け、この体験に必要な表現と操作を育てます。

## 起動

Node.js 22.12以降を使用します。

```sh
npm ci
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。初回の「飛ばす」または音ボタンで音声を有効にします。ヘッドホンを推奨します。

```sh
npm test            # コアの自動テスト
npm run check      # TypeScript
npm run build      # dist/ に静的Webアプリを出力
npm run preview    # ビルドのローカル確認
```

ブラウザ操作の再検証は、開発サーバーを起動してから実行します。

```sh
npx playwright install chromium
npm run test:browser
npm run test:airspace
```

## 遊び方

1. 「大きな旋回」「八の字」「ゆるい起伏」を選ぶか、「一筆で描く」で航路を描きます。
2. 点をドラッグし、高さを調整します。機体が飛べるよう、線は滑らかに整えられます。
3. 「この航路で飛ばす」を押すと設計線が消えます。ドラッグで空を見回し、目のボタンで拡大できます。
4. 各地点で発した音が、距離に応じて遅れて届きます。その発音位置に薄い線と輪が現れます。
5. 一周後は「もう一周、眺める」。次周は低い音の層だけが少し変わります。眺める場所を変えると、同じ飛行でも音の到来が変わります。

Enterで開始、Spaceで一時停止、Escで編集へ、Fで全画面表示。入力欄・ボタンにフォーカスがある間は、通常のキーボード操作を優先します。

航路は同じブラウザのlocalStorageに保存します。音・表示の設定から音量、遅延倍率、控えめな表示を選び、体験ログをJSONでダウンロードできます。タブを離れたときは一時停止します。

### 空のにぎわいを変える

「空のにぎわい」で1〜3機を選びます。追加機は描いた航路を別の位置で飛び、尾翼の色で見分けられます。開始間隔は同時・8秒・16秒。「注目機を聴く」と「空全体を聴く」は飛行中にも切り替えられます。ST-01〜03を押すと、その機体に注目し、ほかの音を控えめにします。カメラは自分で向けます。

「管制案内を表示する」をONにすると、予定や飛行開始を字幕で案内します。現時点では定型案内で、AI・音声読み上げは未接続です。機体が近くを通る間は、字幕表示を控えます。機数・開始間隔・聴き方の設定は再読み込みで初期値に戻ります。

## この版の範囲

| 実装済み                                     | 状態                                                 |
| -------------------------------------------- | ---------------------------------------------------- |
| 航路プリセット・描線・制御点編集・高さ・Undo | PCのポインター操作、狭い画面に対応                   |
| 閉曲線のコンパイル                           | 平滑化、旋回拡大、高度勾配制限、等距離サンプル       |
| 1〜3機の飛行と開始間隔                        | 機体ごとに位置・向き・バンク、発音・音到来を管理       |
| 機体別の音量配分                             | 注目／全体、滑らかな切り替え、機体ごとの発音枠       |
| 管制字幕                                     | 任意表示、飛行イベントからの定型案内、間隔・寿命あり |
| 音の到来                                     | 発音位置と観測者の距離、遅延倍率、Doppler近似        |
| 音航跡                                       | 到来済みの発音位置に線・輪を表示、寿命・数の上限あり |
| 周回・ルール演出                             | 次周の低音層を変更、AIサービス不要                   |
| 保存・ログ・初期化                           | 端末内保存、JSON出力、Reset                          |

機体は固定の検証用メッシュ、音は検証用の合成音です。58 m/sは観察体験を作るための仮設定です。追加機の配置は比較用で、衝突回避はありません。実機の飛行性能、録音素材の音色、WebXR、複数人参加、MR、LLM連携は未実装です。
