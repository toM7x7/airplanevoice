# 試遊と発見の記録

## 2026-09-15 / v0.1 / ユーザーによる試遊

**観察された発言**

- 「こういうのがまさに欲しかった」
- 「音が立体音響っぽくなってて、どっちにいるんだろうって向く瞬間が、すげえ楽しかった」
- ARで体験すること、機体・音・空を磨くことへの期待。
- 複数Questで同じ空を共有したい。複数の機体が鳴るときの調整も必要という意見。
- AIは「管制官のような案内・調整役」と明確化。

**解釈**

音から機体を探す行動に、このユーザーが求める楽しさがある。次の磨き込みでは、発見のきっかけになる音と、見つけたときの機体の存在感を優先する。

**記録の限界**

1人の定性的な感想。使用ヘッドホン、出力音圧、音色の正確さ、他の人での再現性は未測定。Questの実機評価ではない。

## v0.2 / 次の聴き比べ

コード・ブラウザの検証結果は[開発と検証](development.md)と`progress.md`に記録する。以下の人による試遊はまだ実施していない。

| 比較 | 見たいこと |
| --- | --- |
| 1機 → 3機、同時開始 | 音が増えても方向を探したくなるか。耳が疲れないか |
| 3機、同時 → 8秒 → 16秒間隔 | 空のにぎわいと聴き分けのバランス |
| 空全体 → 注目機 → 別の注目機 | 背景機の存在を感じながら、目当ての機体を追えるか |
| 管制字幕OFF → ON | 案内が場面の理解に役立つか。空から視線を奪わないか |
| 草原 → 丘 | 同じ予定で、方向・遅れ・距離感に違いを感じるか |

試遊後は「良かった瞬間」「邪魔だった瞬間」「次に一つ変えるなら」を短く残す。自動テストの合格を、楽しさや音の心地よさの評価に置き換えない。
