# 機体案・景色の文字相談と建物による音の遮り

## 操作

- 機体：PCの「つくる」→「AIと相談する」→文字欄→「Jevで機体案を作る」。Jevは決められた候補から下書きを選ぶ。保存と出発は利用者が確定する。
- 景色：「空を眺める」→「空間づくり」。ここに「景色の名前」と「作りたい景色を文字で相談」を配置。相談は通常のAI操作アシストを使用する。Jev専用の景色生成ではない。
- 名前と景色は「みんなの空に反映」で共通空間に保存・同期する。複数の景色を名前で保存するライブラリはまだない。
- 「建物で音がこもる表現を試す」は任意。初期状態はオフ。PCの自由視点などで位置を変えて比較できる。VRは定位置での安全な観察を基本とする。

## 修正の理由

以前は5問に同じ一般的な指示を渡し、1問でも confidence < 0.55 なら案全体を破棄していた。質問IDはモデルに見えないため、形・尾翼色・胴体色・エンジン数・翼端を各問の指示に明記した。

- 公式仕様：https://docs.typesafe.ai/primitives/choice
- confidence参考：https://docs.typesafe.ai/confidence

正しい形式の回答について項目ごとに信頼度を判断し、曖昧な項目は現在値を保持する。形式不正・未定義候補・確率分布不正は従来どおり拒否。形の変更によって、維持対象の色やエンジン数をプリセットで上書きしない。

景色パネルがAIパネルを覆っていたため、景色用の文字欄をパネル内に設置した。一般のAI文字欄も上部へ移動。Jev案の適用後も、変更・保留の説明が操作完了メッセージに消されないようにした。

## 音の範囲

音の発生位置（遅れて届く音の過去の位置）から現在の聴取位置までを直線で調べ、建物の箱形状を通る厚さで既存の音量・ローパスフィルターを調整する。追加AudioNodeなし。最大40%減衰、高音側の上限1800→800Hz。空間設定変更時だけ建物リストを更新する。

反射・残響・回折や室内音響の物理再現は含まない。ARで仮想建物を隠している間はこの効果も無効。実Questスピーカーでの印象・適切な強さは要確認。
