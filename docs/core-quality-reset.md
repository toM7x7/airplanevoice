# 原点へ戻す品質改善 / 2026-09-22

## 中心となる体験

原本の青写真・企画書を再読。「日常の快晴の空に、大きな四発機が悠然と現れ、後から音が届く」を最優先とする。制作・格納庫・AIは、その一機に愛着を持ち、もう一度見上げるための支援。原資料のXRift案や精密物理の提案は、最新の独立Webアプリ・軽量飛行方針を上書きしない。

## 最新の修正方針

実機評価で「深い響き以外は飛行機らしくない」と判明。候補同士の大きな違いを品質目標から外し、深い旅客機音を共通の標準に変更。PCはファン・気流の控えめな差と詳細編集、VRは標準音を聴いて次へ進める。回転数の実測再現は未実装。距離・過去の発音位置・到来時間のずれを最優先する。既存保存設定は維持するので標準音を選び直せる。

## 前回の反映（上記で方向を修正）

音色エンジンの共通低音が支配的だったため、独立した乱数源の胴鳴り／気流と、中域倍音を持つファンへ再構成。パラメータの混合比の差を拡大し、空気成分に合わせた帯域処理へ変更。3候補も再調整。既存保存データの3パラメータ形式は維持するが、同じ保存設定でも音の響きは新版になる。音源の信号レベルを揃える処理は維持する。体感音量の同一を保証するものではない。

## 工程と受入（完成率ではない）

| 順序 | 内容 | 現状と次の確認 |
|---|---|---|
| 1 | 旅客機らしい共通音と遅れて届く音 | 深い響きへ統一。PCは小さな配合差を編集。距離・到来位置・遅延は維持。聴感は本人評価 |
| 2 | 眺める入口を簡潔にする | VR入場を上部に配置。制作は形と色→共通音→名前→飛ばす。補助操作を削減、閉じて眺める／最終画面のAR観察へ |
| 3 | VRを離れず名前を付ける | 空間キーボードを実装。かな・カナ・大文字英数字、濁点・半濁点・小文字、削除・全消去・確定・取消。漢字変換はPCで入力。実機で読みやすさ・指の押しやすさを確認する |
| 4 | 模型を手元で扱う | メニュー基準で手元に配置。XRのつまみ／トリガー保持で移動と回転、ボタンで回転・拡縮・リセット。PCは模型ドラッグと同じ調整ボタン。尾翼3色は保存・共有・飛行へ引継ぎ。実寸飛行の縮尺は変えない |
| 5 | 出発・帰還と作品の呼出し | 名前付き格納庫と飛行への引継ぎを使用。離発着・途中帰還は別の後続工程 |

## 雲と軌跡

「雲」は飛行機雲を含む話として仮整理。白い飛行機雲は常時必須にしない。大気条件による有無・残り方は表現設定として扱い、未実装の気象シミュレーションを再現済みと言わない。音の軌跡の可視化と飛行機雲は別設定にする。機体を見惚れる際に邪魔なら消せることを優先。
