# VR制作・AR観察・PC編集のまとめ確認

更新: 2026-09-22。Cloudflare公開版へ反映済み。Quest 3＋運営PCが基本。

[公開版を開く](https://airplanevoice-shared-sky.tomohaya-falcon-aramaki.workers.dev/?shared=1)。USB接続なしでもQuest Browserから利用できる。ローカル版も引き続き利用可能。

## VRで一機を作る

1. USB接続したQuest Browserで `http://127.0.0.1:8787/?shared=1` を開く。部屋は先に作らなくてもよい。「飛ばす」で部屋を準備して出発する。既存の部屋に参加する場合は招待URLを使う。
2. 「Questで体験をはじめる」または「VRで体験をはじめる」。
3. 「一機をつくる」で左列で形、右列で尾翼の色を選ぶ。選択した色には✓が付く。「次へ」。
4. 音は共通の「重く、深い響き」。保存済みの古い設定ならこれを選び直す。「今の音を聴く」は任意。「次へ」。
5. 候補名を選ぶか「VR内で名前を入力」。かな／カナ／ABC、濁点（は→ば→ぱ）、小字、消す、全消を使い「確定」。取消なら元の名前を保持。漢字変換はPC側で行う。
6. 「この機体を飛ばす」で部屋に登録し飛行する。「閉じて眺める」で制作を閉じる。AR対応で入場できていれば「ARで眺める」でも同じ飛行を観察できる。

音声AIはこの操作に必須ではない。名前入力も音声は不要。

## 手元の模型

- 制作画面の「模型を動かす」：左右回転・大きく／小さく・手元へ戻す・向きを戻す。
- 模型に向けてピンチまたはトリガーを保持し、手を動かすと模型を移動・回転。離すと止まる。パネルの操作ボタンを押した場合は模型をつかまない。
- メニューの「手元へ呼ぶ」でもメニューと模型の基準位置を更新する。
- 名前入力中は模型を隠して、文字を遮らないようにする。
- 拡縮・回転・位置は観察用模型だけ。飛行する実機の寸法や航路、音の距離計算は変わらない。
- つかみ操作の実機での自然さは要確認。操作しづらければ同じ調整をボタンで行える。

## PCで細かく作る

- 模型をドラッグして回転。調整ボタンで拡縮とリセット。
- 「数値で細かく調整する」で寸法・音の配合を編集。名前欄は通常のキーボードで漢字も入力可能。
- 尾翼色は3候補。保存・呼び出し・部屋登録・飛行に引き継ぐ。
- 保存先はブラウザ／期限付きの部屋。恒久クラウド保管とは異なる。

## 今回まとめて確認する4点

- VRを出ずに名前を付け、取消・確定できるか。
- 指やコントローラーで模型を扱いやすく、メニューを遮らないか。
- 名前と尾翼色が飛行・再呼び出しでも残るか。
- VR／ARで一機を眺め、過去の飛行位置から遅れて届く音を楽しめるか。

自動検査・疑似XRの結果と、上記の実機受入は別に記録する。離発着・途中帰還、気象条件付きの飛行機雲、漢字IMEは今回の完成範囲に含めない。


## 2026-09-22 実機フィードバックへの追補

- 制作画面下段の「ARで見る／VRに戻る」で制作を保ったまま切替。空のメニューにも「ARに切り替える／VRに戻る」を配置。
- ARで「手元に模型を出す」を押すと、今の制作中の機体を一度で呼び出せる。保存作品は「保存した機体」から名前を選ぶ。
- 部屋未作成なら飛ばす操作から自動作成・接続・飛行受付。通信エラーは表示し、再操作可能。受付中と次便待ちは二重送信を避け、待ち時間を表示する。
- 机の位置合わせを使用していない場合、VR中に部屋へ入っても位置合わせ画面へ移さない。既に机を配置した端末の基準変更時は再配置を必要とする。
- 模型は実際の形へのレイ命中でつかむ。保持開始時の相対位置も手の回転に合わせて回転させる。Quest実機の指の追従感は追加確認が必要。
- 格納庫は同名・同設定の重複をまとめ、4機ずつ・ページ番号付きで選択。20機の一覧・最終ページ・戻る・呼び出しをエミュレーターで確認。20機同時飛行を実装したという意味ではない（従来の同時飛行数を維持）。
- 自動検証: 189 unit tests、ビルド、XR模擬操作による飛行・切替・呼び出し。実機ARの背景合成と指操作の自然さは別途確認。
