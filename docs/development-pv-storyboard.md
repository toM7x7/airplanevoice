# AIRPLANEVOICE 開発PV / 絵コンテ

2026-09-22。制作中の体験を紹介する約60秒の横動画。実装済みの録画と今後の構想を明確に区別する。公開・外部投稿はしない。

## コンセプト

**見上げた空に、あなたの一機。**

旅客機が飛ぶ姿と音に見惚れる。形と響きを自分で選び、名前をつけ、同じ空へ送り出す。AIは制作と操作を手伝い、空の状況から注目点を拾う。主役はAIの性能ではなく、空を見上げたくなる体験。

## 撮影・編集方針

- 16:9 / 30 fps。元の録画が滑らかに動いていることを確認し、フレーム数の水増しだけで滑らかとしない。
- 明るい空、温かい白、深い緑。読みやすい日本語。短いフェードとカット中心。
- 参加用キー、URLの秘密部分、APIキーを入れない。独立した撮影用ローカル部屋を使う。
- PCは実際のWebGL描画とWeb Audio出力を録る。撮影用操作であり、ユーザーの部屋は操作しない。
- Questはユーザーの操作を録画。ステレオ画面は片目を切り出す場合に注記。パススルーの個人空間を使わない。
- 有料APIを撮影のため繰り返さない。AIの役割説明と、実装されたツール受け口の検証を分ける。
- 新しい格納庫画面や比較試聴を完成したように合成しない。

## 確認するもの

元動画と編集後の動き、映像・音声の尺、フリーズ、音のピーク、字幕の可読性、実装／模擬／構想の表示。QuestのUSB接続成功はWebXR体験・指操作の全項目合格を意味しない。

## 制作結果

- `output/pv-20260922/airplanevoice-development-pv.mp4`：60秒、1920×1080、30fps、1800フレーム。
- `output/pv-20260922/review.html`：動画と6カットの静止画。
- `output/pv-20260922/verification.json`：フレーム・音声・元素材の測定結果。
- PCの制作操作、模擬AIによる下書き変更／飛行ボタン強調、本人操作での飛行開始を撮影。JS例外なし。有料AIへの呼出しなし。
- Quest 3の実機操作を約60秒収録し、20〜32秒のアプリ画面だけを採用。ホーム画面や実際の部屋は不採用。音声トラックなしのため、Questカットは無音。
- 観察映像は制作模型を閉じて撮り直し、頭上通過を採用。既存の「機体の方を向く」を撮影補助として連続実行した映像であり、新しい自動追尾機能ではない。
- 動き検査：飛行・Quest各3秒で、隣接89組すべてに画面変化を確認。PC編集の停止時間は操作待ちを含む。
- 元録画平均：約29.9fps（PC飛行）、約29.6fps（PC操作）、約66.5fps（Quest）。PC元録画には最大165〜200msの間隔もあるため、実機性能や常時滑らかな描画の保証とはしない。
- 出力音声ピーク0.322、クリッピングなし。音源はPCアプリのエンジン音。ナレーション・BGMなし。
- 今回の試遊指摘は `quest-playtest-2026-09-22.md`。名前はキーボード入力、音声命名を要求しない。アプリのUI改修は未実施。
