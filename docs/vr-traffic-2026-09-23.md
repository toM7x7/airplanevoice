# VRの操作整理・同時飛行拡張・裏方Jev

更新: 2026-09-23

公開反映済み: [共有展示入口](https://airplanevoice.pages.dev/?shared=1)。Worker `10411b47-6b7d-4581-bd28-dee777cee2d1`、Pages `0c74d736`、bundle `f6409a62019274ba`。公開HTML・JS・オフラインキャッシュの版一致、共有接続、標準6機、Jevオフ、運営UI、模擬両眼VRの共通バーを確認。既に開いている端末は再読み込みする。

## 今回の到達点

旅客機を見上げ、遅れて膨らむ音を楽しむ体験を中心に、共有の空を3機固定から拡張した。標準6機、運営画面で3・6・9・12機を選べる。9・12機はQuestで負荷を確かめて使う。保存上限24機、同時接続上限4端末は今回変更していない。

- 全機が終わるまで待つ方式から、枠が空くごとに次の自動便を出す方式へ変更。
- 手動の「この機体を飛ばす」は未出発の自動便より優先。空きがあれば15秒後に出発する。満枠時には音の余韻を含めた空き待ちとなる。
- 格納庫の機体を順番に使用。自動便は基準高度140〜492mの候補から重なりを避ける。保存したレシピ・飛行中の航路は変更しない。
- 飛行中のIDと名前、音源を維持し、先発機の退場で別の機体に入れ替わらない。
- 音声処理は全体で最大24音源。6機時は各4、12機時は各2を上限とする。遅延して届く音と空間定位は維持する。

## VR・ARの操作

共通の下部バーに「メニューを開く／閉じる」「ARで見る／VRに戻る」「手元へ呼ぶ」。音量・設定・AI相談・保存機体・飛行一覧は「空のメニューに戻る」を同じ位置に配置した。変更する選択肢、画面移動、飛ばす主操作の表示を分ける。

飛行一覧は4機ずつ表示し、前／次で切り替える。名前を選ぶと距離や高さを確認できる。ブラウザへ戻る操作は「音・見え方の設定」にまとめた。左右の取っ手による移動、手を離した後の固定は維持する。

高度な会場位置合わせの各ページは従来の構成。今回の共通化は日常的に使う主要ページが対象。

## Jevの役割

PCの「部屋・運営」→「空の運行管理」→「Jevで出発間隔を自動調整」でオンにする。初期値はオフ。来場者のVRにはJevを開始するボタンを置かず、GPTとの会話・編集相談を残す。

| 担当 | 今回行うこと |
| --- | --- |
| Jev | 飛行枠、機体名、高度、速度、開始・終了予定、待機・余韻を読み、次の自動出発の間隔を15／30／45秒から選ぶ |
| サーバーのコード | 容量、開始時刻、音の余韻、手動便優先、基準高度の割り当てを確定する |
| GPT-Live | 利用者との会話、編集支援、操作案内。今回の裏方管制とは別の接続 |

Jevは部屋ごとに1系統。端末数分の重複呼び出しを避け、接続者がいて自動運行がオンの間だけ、最短30秒間隔で判断する（上限目安120回／時／部屋。実際は飛行アラームの間隔に依存）。利用回数を運営画面に表示する。既存の `TYPESAFE_API_KEY` を使用し、ブラウザへ鍵を渡さない。

2.5秒の応答待ち、選択肢と確率分布の検証、古い返答の破棄を入れた。失敗時は規則で継続。飛行中の回避操縦や衝突回避の保証はない。高度は航路の基準値の分離であり、三次元の全軌跡が交差しない保証ではない。

## 検証

- 単体225件、アプリビルド、Worker型検査。
- PC＋IWER模擬XR16項目：制作、名前入力、保存・呼出、AIツールの模擬応答、手動出発、AR切替、主要画面の戻り先。
- 掴み5項目：手とコントローラー、入力切替、無関係なピンチ、解放後の固定。
- ローカル共有サーバーで容量3／6／9／12の保存を確認。12機の模擬スナップショットを両眼描画し、3ページ・12機目の選択を確認。
- Web Audioの実波形：6機は45/45、12機は44/45サンプルで全機が同時発音。最大24音源、ミュート・音量0・停止を確認。
- Jevの応答検証・再試行抑制・操作と競合した遅延返答はモックで検証。有料AI呼び出しは行っていない。

証拠: `output/traffic-vr-2026-09-23/`。同時に複数の負荷試験を走らせた際、長時間シミュレーション1件が5秒のテスト制限に達した。55回のアラームと途中参加を検証する当該試験の制限を15秒に明示し、全件を再実行した。

## Quest 3で確認する順序

1. 公開ページを再読み込みし、標準6機でVRに入る。
2. 飛行一覧→2ページ目→機体選択→戻る。名前と音が入れ替わらないかを見る。
3. 音量・設定・AI相談から戻る位置、AR／VR切替、左右の取っ手での移動を確認。
4. 新しい機体を飛ばし、出発待ちと既存機が同時に分かるかを見る。
5. 重さや聞き疲れがなければPCで9機、12機へ。重い場合は3／6機へ戻す。既に飛行中の機体は消去せず、自然に減るまで次便を控える。
6. Jevをオンにして実サービスの判断・費用を確認するのは別の確認項目。

模擬XRの描画・波形は、Questでの滑らかさ、聞き分け、文字の見やすさの受入確認とは別。会場連携はこの基本体験を確認した次の段階。
