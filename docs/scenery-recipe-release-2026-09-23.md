# 景色の相談を下書き作成へ接続

## 問題と変更

「パリの街並みと東京の高層ビル群を混ぜたい」のような依頼が、一般の操作案内へ流れ、プリセットやメニューの説明で終わっていた。

PC「空間づくり」の文字入力を専用の景色案作成へ接続した。既存OpenAIキーとgpt-4.1-miniの構造化出力を使い、景色の名前、種類、高さ、密度、通りの幅、緑、配置番号、建物音の1案を返す。全設定を検証して一度にローカルの下書きへ反映する。「みんなの空に反映」を押すまで共有しない。待機中に編集された景色は上書きしない。

Jevの機体案やGPT-Liveの音声接続を変更する修正ではない。現在の景色は箱形建物、木、水面等の組み合わせであり、都市固有の屋根や建築様式を生成する機能は含まない。AIにもこの制約を渡し、結果に説明させる。

## 検証

- 258 tests / 50 files、Worker型検査、Viteビルド成功。
- 専用プロバイダー：完全な下書き、範囲外・未知フィールドの拒否、PC以外で呼ばないことを検査。
- AI固定応答のUI検証：文字入力→名前と複数パラメータの下書き→本人の共有操作→別ブラウザで同期。Jev部分採用の既存動作も確認。
- 公開AIの独立セッションで1回問い合わせ。約4.5秒で `city / heightM 70 / density 0.75 / streetWidthM 54 / greenery 0.15` と名称・制約説明を取得。共有ルームへの書き込みは0。少数の確認であり、すべての文章への品質保証ではない。
- 公開HTML・JS・Service Worker、既存の運営設定、音響マップ、模擬XR両眼描画を確認。今回の共有接続は成功。実Questの操作・聴感は未再検証。
